# Zenith Anime — Frontend

A responsive anime browsing web application built with React.js and Bootstrap.

## Pages

| Page | Description |
|------|-------------|
| Home | Hero section with live search |
| Movies | Browse all anime movies |
| TV Shows | Browse all anime TV shows |
| Trending | Currently trending anime |
| Anime Detail | Full info page for a single anime |
| Login | Sign in to your account |
| Register | Create a new account |
| Contact | Send a message |
| 404 | Page not found |

## Technologies

- React.js (Create React App)
- React Router v6
- Bootstrap 4.5.2
- LocalStorage for session management

## Getting Started

1. Make sure the backend server is running first (see `anime-backend`)
2. Install dependencies:
   ```
   npm install
   ```
3. Start the development server:
   ```
   npm start
   ```
4. Open [http://localhost:3000](http://localhost:3000)
